Hubungkan Google IDP

Dashboard membaca IDP pusat melalui mirror Google Sheet milik ETOS. Sheet pusat tidak diubah. OAuth dashboard hanya meminta izin membaca Google Sheets.

Belum terhubung

Client ID dan Client Secret hanya dikirim ke backend ETOS melalui HTTPS lalu disimpan terenkripsi di Supabase. Nilainya tidak disimpan di browser.

Aktifkan Mirror Live

Cukup satu kali: paste formula ke A1 lalu klik Allow access / Izinkan akses. Setelah itu data mengikuti IDP pusat otomatis.
  1. Buka mirror ETOS dari tombol di bawah.
  2. Pilih tab Sheet1 dan klik sel A1.
  3. Klik Salin formula sinkronisasi, lalu paste ke A1.
  4. Saat muncul #REF!, klik Allow access / Izinkan akses.
